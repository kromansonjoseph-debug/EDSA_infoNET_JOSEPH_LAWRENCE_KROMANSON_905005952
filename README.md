Executive Summary
EDSA-infoNET is an informative, user-friendly 5-page web application designed and developed for the Electricity Distribution and Supply Authority (EDSA) in Sierra Leone. The project serves as a digital bridge between EDSA and the public, providing structured access to essential power utility services, tariff guides, prepaid meter acquisition workflows, maintenance requests, and corporate transparency.
Designed specifically to meet strict academic and industry standards, the web application addresses real-world civic needs across Freetown and regional Sierra Leone. It delivers clear information regarding prepaid token acquisitions, residential and commercial tariffs, grid expansion initiatives, and direct customer support channels—all executed with high usability and zero dynamic script dependencies.

Key Features & Highlights
Prepaid Meter Application Workflow: Interactive interface for selecting single-phase, three-phase, and industrial meters with transparent pricing.
Pure CSS Modal Form: Interactive service request and application dialogs functioning seamlessly without any JavaScript.
Comprehensive Tariff & Billing Guide: Detailed breakdown of residential ($0.25/kWh) and commercial ($0.34/kWh) energy rates and fixed charges.

Customer Support Hub: Direct contact details for customer care representatives, toll-free lines, WhatsApp channels, and physical address routing.
Corporate Transparency & Progress Tracking: Coverage of key energy milestones including the $480M MCC Compact, CLSG regional grid connectivity, and leadership directories.
Technical Standards & Architecture
100% Pure HTML5 & CSS3: Strict adherence to frontend standards using only semantic HTML syntax and pure CSS styling. No JavaScript (.js files, <script> tags, or inline onclick/onsubmit handlers) is utilized anywhere in the application.
Pure CSS Interactivity: Dynamic modals and pop-up overlays are implemented exclusively through the CSS :target pseudo-class combined with HTML anchor links (#serviceModal / #).
Cross-Browser Compatibility: Optimized and verified for flawless rendering on Mozilla Firefox and modern web browsers.
Standardized Navigation: Identical navigation bars and relative link structures (index.html, about.html, services.html, contact.html, features.html) across all pages to prevent broken links or navigation errors.
Website Structure & Page Overview
Home (index.html)
Overview of EDSA’s primary mandate, mission, and vision.
Progress reports on prepaid meter deployment, national power access, the MCC Compact, and regional CLSG power integration.
Stakeholder and executive board directory.
About Us (about.html)
Historical evolution of power utilities in Sierra Leone (from NPA to EDSA).
Organizational structure breakdown and active career vacancy opportunities.
Services (services.html)
Meter tier options: Single-Phase Residential (Le 2,500), Three-Phase Commercial (Le 3,500), and Industrial (Le 4,500).
Pure CSS modal forms for meter purchasing, maintenance dispatch, and account name/ownership transfers.
Contact Us (contact.html)
